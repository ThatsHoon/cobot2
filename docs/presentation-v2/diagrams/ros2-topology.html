cobot2 — ROS2 Topology (7 nodes · 4 groups)

노드 7개를 기능별 4그룹으로 묶으면 한눈에 — 핵심 토픽 4개 · 액션 1개 · 서비스 1개

왜 4 그룹으로 묶나?

  • • 7개 노드를 외울 게 아니라 역할로 이해
  • • 음성·뇌·손·관측 = 인간 신경계 비유
  • • 노드 추가/제거가 그룹 안에서만 일어남
  • • 통합 전 14노드 → 후 7노드(절반 감축)

왜 Service가 1개뿐?

  • • 비전·파지 단일 진입점 통합 결과
  • • mode = "locate" / "grasp" 두 모드
  • • 이전엔 비전·파지 노드 분리 + 토픽 다수
  • • 호출 인터페이스 단순화 = 디버깅 쉬움

안전은 별도 토픽 채널

  • • /admin_command : ESTOP/UNLOCK 입력
  • • /admin_result : 3단 정지 결과 가시화
  • • TRANSIENT_LOCAL = 늦게 떠도 마지막 결과 수신
  • • silent 실패 방지가 핵심 설계 원칙
