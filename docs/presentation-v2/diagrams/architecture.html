cobot2 — System Architecture

2개 PC가 음성 게이트웨이와 로봇 두뇌로 역할 분담, 외부 AI / DB / 하드웨어와 통합

왜 PC가 2대인가?

  • • 음성·LLM은 비실시간 (응답 2~5초)
  • • 로봇 제어·비전은 실시간 (수십 ms)
  • • 한 PC가 둘 다 = GIL/CPU 경합
  • • 책임 분리 = 안정성 + 장애 격리

두 PC 사이 단일 접점

  • • `/voice_command` 한 토픽으로 두 PC 연결
  • • CycloneDDS · launch가 DDS env 강제 주입
  • • 운영자 누락 방지 (ros_domain_id arg)
  • • 음성 PC 다운 ≠ 로봇 PC 다운

DB-only 컨테이너 패턴

  • • Docker DDS 디스커버리 어려움 → 우회
  • • db_logger가 호스트에서 ROS→MySQL 적재
  • • 컨테이너는 DB만 read
  • • transaction · /diagnostics dedupe

cobot2 · 2 PCs · 7 ROS2 nodes · 약 10,800 LOC (py + cpp + sql)
