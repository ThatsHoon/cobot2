SECTION 02 · HAND-EYE CALIBRATION

카메라 좌표 → 베이스 좌표 — 5° 기울임의 해결

카메라가 5° 아래로 기울어진 환경에서 depth 오차가 발생.
cv2.calibrateHandEye() 로 4×4 변환 행렬을 사전 계산해 런타임에 보정.

# T_gripper2camera.npy (4×4, 단위: mm) [[ 0.999 -0.012 0.034 -28.3 ] [ 0.013 0.999 -0.018 12.1 ] [-0.034 0.019 0.999 112.5 ] [ 0. 0. 0. 1. ]]

파일 미발견 시 RuntimeError — fail-fast 설계 (무음 실패 방지)

5° 기울임이 없으면 이 캘리브레이션이 필요 없다는 점 강조.
